0. 시작하기 전에

이 가이드를 끝까지 따라하시면 매일 반복되는 학원 운영 업무 (출결·수업기록·수강료 안내·상담 기록 등)를 한국어로 부탁만 하면 자동으로 처리되는 시스템을 갖게 됩니다.

예상 소요 시간

  • 30~60분 (PC 사양·인터넷 속도·노션 사용 숙련도에 따라 다름)
  • 대부분의 시간은 다운로드·설치 대기. 사용자가 직접 타이핑할 양은 매우 적습니다.

필요한 것

  • PC 1대 (Windows 또는 Mac, 인터넷 연결)
  • 노션 계정 (이미 사용 중이실 것)
  • 이메일 주소 (Anthropic 계정 만들 때 사용)
  • (선택) 디스코드 계정 — 수강료 안내·일일피드백 자동 발송에 쓰입니다. 안 쓰셔도 셋업·다른 기능은 모두 동작합니다.

이 가이드의 핵심 컨셉 — "Claude가 알아서 안내"

받으시는 분의 컴퓨터 환경은 천차만별입니다 (Windows·Mac, 다른 사용자명, 다른 폴더 구조). 그래서 이 가이드는 환경별로 일일이 명령어를 적지 않습니다. 대신:

받으시는 분이 직접 해야 할 일은 단 두 가지입니다.

  1. 3번 섹션의 자연어 한 줄을 그대로 복사·붙여넣기
  2. Claude가 물어보는 것에 한국어로 답변

OS 감지, git 설치 여부 확인, 폴더 위치 추천, 파일 다운로드, 설정 파일 작성 등 나머지는 Claude가 대화하면서 알아서 진행합니다.

1. Claude Code 설치 (10분)

Claude Code는 Anthropic에서 만든 공식 도구입니다. 한국어로 부탁하면 컴퓨터의 파일·폴더·노션 등을 알아서 처리해주는 비서라고 생각하시면 됩니다.

1-1. 다운로드

  1. 브라우저로 claude.ai/code 접속
  2. 페이지가 본인 OS(Windows / Mac)를 자동 감지해서 설치 파일을 안내합니다.
  3. 설치 파일 다운로드 → 실행 → 안내에 따라 설치

1-2. Anthropic 계정 로그인

  1. 설치 후 Claude Code를 실행하면 로그인 화면이 나옵니다.
  2. Anthropic 계정이 없으시면 "Sign up"으로 만드시고 (이메일·비밀번호) 바로 로그인.
  3. 로그인이 완료되면 검은색 화면에 "What can I help you with?" 같은 안내가 보입니다.

1-3. 첫 화면 사용법

Claude Code는 한국어 자연어로 부탁하면 됩니다. 어려운 명령어를 외우실 필요 없습니다.

예: "내 다운로드 폴더에 뭐가 있는지 보여줘"라고 한국어로 입력해도 답변합니다.

2. 노션 템플릿 받기 + 연동키 만들기 (10분)

2-1. 노션 학원관리 템플릿 복제

  1. 옥토퍼스코딩에서 받으신 노션 학원관리 템플릿 링크를 브라우저에서 엽니다.
  2. 오른쪽 상단의 "복제(Duplicate)" 버튼 클릭 → 본인 워크스페이스 선택
  3. 복제가 완료되면 본인 워크스페이스 안에 학원관리 페이지가 생깁니다. 이 페이지가 부모 페이지가 됩니다.

2-2. 노션 Integration(연동키) 만들기

Claude가 본인의 노션에 접근하려면 "연동키"(Integration Secret)가 필요합니다. 일종의 열쇠라고 생각하시면 됩니다.

  1. 브라우저에서 notion.so/profile/integrations 접속
  2. 오른쪽 위의 "+ New integration" 클릭
  3. 이름 입력 (예: "Claude 학원관리"), 워크스페이스 선택 → 저장
  4. 생성된 페이지에서 "Internal Integration Secret"이 보이고 옆에 "Show" / 복사 버튼이 있습니다.
  5. 이 키를 복사해서 메모장에 임시로 저장해두세요. ntn_ 으로 시작하는 긴 문자열입니다.
주의 — 이 연동키는 일종의 비밀번호입니다. 다른 사람에게 보여주거나 SNS·공개 게시판에 올리지 마세요.

2-3. 복제한 부모 페이지에 Integration 연결

  1. 2-1에서 복제한 학원관리 부모 페이지로 돌아갑니다.
  2. 오른쪽 상단의 "..."(점 세 개) 클릭 → "연결(Connections)" 메뉴
  3. 방금 만든 Integration(예: "Claude 학원관리") 선택
  4. "확인"으로 권한 부여

이제 Claude가 이 페이지와 그 아래의 모든 DB(학생·반·시간표 등)에 접근할 수 있게 됐습니다.

2-4. Claude Code에 노션 MCP 활성화 + 연동키 등록 (가장 중요)

Claude Code가 본인의 노션에 직접 접근하려면 노션 MCP(연결 도구)를 활성화하고, 2-2에서 만든 연동키를 등록해야 합니다. 이 단계를 건너뛰면 다음 섹션의 셋업이 중간에 멈춥니다.

  1. Claude Code를 켭니다.
  2. 설정 메뉴 열기 — Mac은 Cmd + ,, Windows는 Ctrl + ,
  3. "MCP" 또는 "확장 도구" 섹션 찾기
  4. "notionApi" 또는 "Notion" 항목을 활성화
  5. "Internal Integration Secret" 입력란에 2-2에서 복사해둔 연동키(ntn_...)를 붙여넣기
  6. 설정 저장 → Claude Code 재시작
  7. 재시작 후 새 세션에서 /mcp 명령어 입력 → "notionApi" 가 목록에 보이면 활성화 성공
⚠️ 메뉴가 안 보이거나 다른 형태일 때 — Claude Code 버전·환경마다 메뉴 구조가 다를 수 있습니다. 막히시면 Claude Code 창에 자연어로 물어보세요: 
노션 MCP 활성화하는 방법 알려줘.
내 OS는 [Windows / Mac] 이고, Claude Code 메뉴에 MCP 항목이 안 보여.
Claude가 본인 환경에 맞는 방법을 안내해줍니다. PowerShell·파일 편집 안내가 나오면 그대로 따라하지 마시고, "GUI 메뉴로 하는 방법 알려줘"라고 다시 부탁하세요.

이 단계까지 완료되면 본격 셋업 준비 끝입니다. 다음 섹션으로 가시면 됩니다.

3. Claude에게 셋업 부탁하기  ⭐ 핵심 ⭐

이 섹션이 가장 중요합니다. 받으시는 분이 직접 손대실 일은 아래 박스의 자연어를 그대로 복사 → Claude Code에 붙여넣기 → Enter가 전부입니다.

3-1. Claude Code에 붙여넣을 자연어

아래 박스 전체를 복사해서 Claude Code 새 세션에 그대로 붙여넣으세요
교체할 부분이 없습니다. 그대로 복사해서 붙여넣으면, 노션 페이지 주소·연동키 같은 건 Claude가 단계별로 물어봅니다.
이 GitHub repo의 SETUP_FLOW.md를 따라 내 컴퓨터에 노션 학원관리
명령어 시스템을 셋업해줘.

Repo: https://github.com/set-octopuslab/notion-academy-claude-commands
위 박스의 텍스트를 그대로 드래그 → 복사(Ctrl+C / Cmd+C) → Claude Code에 붙여넣기(Ctrl+V / Cmd+V) → Enter

3-2. 그 다음 — Claude가 알아서 안내합니다

Enter를 누르시면 Claude가 다음과 같은 흐름으로 진행합니다. 각 단계마다 한국어로 물어볼 거예요. 모르겠으면 "잘 모르겠으니 추천해줘"라고 답하셔도 됩니다.

Claude가 묻는 것 예시 (실제 순서·표현은 환경에 따라 조금씩 다를 수 있음): 1. "OS를 확인했습니다. Windows이시네요. git이 설치되어 있는지 먼저 확인할게요..." 2. "git이 없으시네요. 설치 파일 다운로드 링크 드릴까요?" → "네" 3. "명령어 폴더를 어디에 두실까요? 추천: 문서 폴더 아래 'notion-academy' 폴더" → "네 추천대로" 4. "노션 부모 페이지에 접근 가능한지 확인 중..." → "확인 완료" 5. "DB 17개를 자동으로 찾았습니다. 매칭 결과 보여드릴게요..." → 확인 후 "네" 6. "디스코드 웹훅 URL 설정하시겠어요? (수강료 안내 발송용)" → "지금은 안 쓸래" 7. "셋업이 끝났습니다. /노션-템플릿연결 명령어로 다시 한 번 검증해볼까요?" → "네"

약 5~15분 정도 걸립니다. 마지막에 Claude가 "이제 /학생-신규등록, /노션-게시판 등 명령어를 쓸 수 있습니다"라고 안내해드리면 셋업 완료입니다.

알아두세요 — Claude가 한 번에 모든 걸 알아서 처리하려고 시도하다가 막히면, 본인이 직접 답하실 수 있게 친절하게 물어봅니다. 답을 모르시면 "추천해줘" / "잘 모르겠어" / "이걸로 해줘"처럼 자유롭게 답하시면 됩니다.

4. 첫 명령어 사용해보기 (5분)

셋업이 끝나면 가벼운 명령어로 동작을 확인해봅시다. 두 가지 추천 시나리오 중 편한 걸 고르세요.

시나리오 A. 가상 학생 등록 (지웠다 다시 해도 됨)

  1. Claude Code에 /학생-신규등록 입력 → Enter
  2. Claude가 학생 이름·학교·학년 등을 차례로 물어봅니다. 가상 이름으로 답변해보세요 (예: "테스트 학생", "테스트초", "초", "3").
  3. 모든 항목 답변 후 미리보기가 나오면 "네"로 진행.
  4. 노션 학생 DB에 가상 학생 row가 생긴 걸 확인하세요.
  5. 확인 후 노션에서 직접 그 row를 삭제하시면 됩니다.

시나리오 B. 게시판에 공지 글 작성해보기

  1. Claude Code에 /노션-게시판 입력 → Enter
  2. Claude가 글 유형·작성자·제목·내용을 차례로 물어봅니다. 키워드만 줘도 Claude가 톤을 다듬어 정리합니다.
  3. 미리보기 확인 후 "네"로 진행하면 노션 게시판 DB에 row가 생성됩니다.
  4. 확인 후 노션에서 직접 row를 지우셔도 됩니다.

5. 명령어 22개 자세한 사용법

아래는 받으신 시스템에 들어있는 모든 명령어입니다. 카테고리별로 묶어 정리했고, 각 카드에는 언제 쓰는지·Claude가 무엇을 묻는지·예상 결과·주의할 점이 담겨 있습니다.

※ 모든 명령어는 미리보기 → "네"로 확인 후 처리 패턴입니다. 잘못 시작했다면 "취소" 또는 "아니오"로 안전하게 빠져나오실 수 있습니다.
학생 관리 (3개)
/학생-신규등록— 신규 학생 + 학부모 정보를 한 번에 등록
▶ 언제 쓰나요? 새 학생이 들어왔을 때. 학생 DB + 학부모 DB 양쪽에 row를 동시에 만들고 자동 연결합니다.
▶ 어떻게 시작하나요? Claude Code에 /학생-신규등록 입력.
▶ Claude가 묻는 것
  1. 학생 이름
  2. 학교 (예: 목동초)
  3. 초/중/고/대
  4. 학년 (1~6)
  5. 성별 (선택)
  6. 학생 전화번호 (선택)
  7. 유입경로 (네이버·당근·인스타·블로그·추천 등)
  8. 실력레벨 (입문·기본·심화·경시)
  9. 진로희망 (선택)
  10. 매월 결제일 (1~31, 기본 1일)
  11. 첫 수업일 (선택, 모르면 빈 칸)
  12. 학부모 관계 (어머니·아버지·조모·조부)
  13. 학부모 전화번호
  14. 주 연락처 여부 + 두 번째 학부모 추가 여부
▶ 결과물 학생 DB row 1개 + 학부모 DB row 1~2개 + 양방향 relation 자동 연결.
▶ 예시
Claude: 학생 이름은? 사용자: 김민석 Claude: 학교는? 사용자: 목동초등학교 Claude: 초·중·고 중 어디? 사용자: 초 Claude: 학년은? (1~6) 사용자: 5 ... (중간 생략) Claude: 학부모 관계? 사용자: 어머니 Claude: 학부모 전화번호? 사용자: 010-1234-5678 Claude: [미리보기 출력] 이대로 등록할까요? (네/아니오) 사용자: 네 Claude: ✅ 등록 완료. 학생 DB와 학부모 DB에 row가 생성됐습니다.
동의서 관련 3개 필드는 자동 채우지 않습니다. 학원 정책에 따라 별도 처리하세요.
/학생-휴원처리— 재원생을 '휴원' 상태로 변경
▶ 언제 쓰나요? 학생이 일시적으로 안 다니게 됐을 때. 시간표·청구서는 자동으로 제외됩니다(데이터는 보존).

▶ 언제 쓰나요? 학원에서 물품을 구매했을 때 내역을 노션에 기록. 영수증은 row 생성 후 노션에서 직접 첨부.
▶ Claude가 묻는 것
  1. 구매한 물건 (예: "화이트보드 마커 5색 세트")
  2. 카테고리 (교구/소모품/사무용품/간식/시설)
  3. 구매자 (선생님 DB에서 선택)
  4. 금액 (숫자 또는 "1만원"·"12,000" 등 — 자동 파싱)
  5. 결제방식 (카드/현금/계좌이체/지역상품권)
  6. 구매일자 (오늘/어제/날짜 직접)
  7. 구매처 (선택)
▶ 결과물 운영 물품구매 DB에 row 1건. 영수증 사진은 노션 UI에서 직접 업로드.
▶ 예시
사용자: /물품구매 Claude: 구매한 물건? 사용자: 학생 간식 음료수 24개 Claude: 카테고리? 사용자: 간식 Claude: 구매자? 1.김선생 2.이선생 사용자: 1 Claude: 금액? 사용자: 1.8만원 Claude: 결제방식? 사용자: 카드 Claude: 구매일자? 사용자: 오늘 Claude: 구매처? (선택) 사용자: 코스트코 Claude: [미리보기] 생성할까요? 사용자: 네 Claude: ✅ row 생성. 영수증은 노션에서 직접 첨부하세요
통계·정산·알림은 이 명령어에 없습니다(노션의 group·sum 기능을 활용하세요).
초기 세팅 (2개)
/노션-템플릿연결— 노션 학원관리 템플릿 자동 매핑 (셋업 시 자동으로 한 번 실행됨)
▶ 언제 쓰나요? 가이드의 3번 셋업 단계에서 Claude가 알아서 실행하는 명령어입니다. 나중에 노션 DB 구조가 바뀌었거나, 새 PC에서 다시 셋업할 때도 사용.
▶ Claude가 묻는 것
  1. 노션 학원관리 부모 페이지 URL
  2. 매칭된 17개 DB 결과 확인 (자동 검색 → 사용자 확인)
  3. 학원명
  4. 노션 Integration Secret (선택, file_upload용)
  5. 디스코드 학부모 웹훅 (선택)
  6. 디스코드 세션 저장 웹훅 (선택)
  7. 수강료 패턴 4종 (기본값 그대로 OK)
▶ 결과물 notion-academy-config.json 파일이 셋업 폴더에 저장됩니다. 이후 모든 명령어가 이 파일을 읽어 동작합니다. DB 필드 검증 결과도 함께 안내.
이 명령어는 노션에 읽기만 합니다(쓰기 X). 안전하게 여러 번 다시 실행하셔도 됩니다.
/노션-초기설정— 노션 DB ID·디스코드 웹훅을 수동 입력으로 저장 (자동 매핑이 실패할 때만)
▶ 언제 쓰나요? /노션-템플릿연결의 자동 매핑이 실패하거나 DB 이름이 매우 달라서 직접 입력하고 싶을 때. 일반적으로는 안 쓰셔도 됩니다.
▶ Claude가 묻는 것
  1. 각 DB 이름으로 검색 → 결과 1건이면 자동 채택, 여러 건이면 목록 표시 후 선택, 0건이면 빈 값으로 둠
  2. 디스코드 웹훅 URL (선택)
  3. 수강료 패턴 4종 (기본값 OK)
▶ 결과물 /노션-템플릿연결과 같은 config 파일을 만듭니다. 다만 자동 매핑이 아닌 수동 입력 기반.
웬만하면 /노션-템플릿연결을 먼저 쓰세요. 이 명령어는 fallback입니다.

6. 자주 묻는 질문 (FAQ)

Claude Code에서 명령어(/...)가 안 보여요
셋업 단계에서 명령어 .md 파일이 Claude Code의 명령어 폴더(~/.claude/commands/)에 복사되지 않은 경우입니다. Claude에게 "명령어가 안 보여요. 다시 셋업해줘"라고 말씀하시면 Claude가 재진단·재복사해드립니다.
노션 Integration Secret(ntn_...)이 뭐고 왜 필요한가요?
Claude가 본인의 노션 워크스페이스에 접근하기 위한 열쇠입니다. 노션은 본인이 명시적으로 허용하지 않으면 외부 도구가 데이터에 손대지 못하게 되어 있어요. Integration을 만들고 학원관리 페이지에 "연결"하시면 Claude만 그 페이지를 읽고 쓸 수 있습니다. 다른 사람·다른 페이지에는 접근 못 합니다.
디스코드 안 쓰는데 어떻게 해야 하나요?
디스코드는 /일일피드백발송·/시간표변경·/휴강등록·/상담예약·/상담기록의 자동 발송 기능에만 쓰입니다. 셋업할 때 디스코드 웹훅 부분은 "없음"으로 두시면 됩니다. 다른 명령어(/학생-신규등록·/수업계획·/수업결과·/주간피드백·/월간피드백 등)는 모두 정상 동작합니다.
에러 메시지가 나와요
에러 메시지 전체를 그대로 복사해서 같은 Claude Code 세션에 붙여넣으시고 "이 에러 어떻게 해결해야 해?"라고 물어보시면 Claude가 진단·수정해드립니다. 한 번에 안 풀려도 괜찮아요 — 7번 '도움 요청' 섹션의 방법대로 Claude와 여러 각도로 시도해보세요.
노션 DB 구조를 우리 학원에 맞춰 바꾸고 싶어요
필드 추가는 안전합니다(명령어가 모르는 필드는 그냥 무시). 필드 이름·타입 변경·삭제는 명령어가 동작하지 않을 수 있어요. 변경 전 Claude에게 "이 필드 이름 바꾸려는데 영향받는 명령어 있어?" 라고 물어보시거나, 변경 후 /노션-템플릿연결로 재매핑·DB 필드 검증을 다시 돌려보시는 걸 권장드립니다.
다른 PC에서도 쓰고 싶어요
새 PC에서 다시 셋업하시면 됩니다. 1번(Claude Code 설치) → 3번(자연어 한 줄 붙여넣기) 순서대로 진행. config 파일을 G드라이브·Dropbox 같은 공유 폴더에 두시면 여러 PC에서 같은 설정을 공유하실 수 있어요(Claude에게 "config 파일을 공유 폴더에 저장해줘"라고 부탁).
명령어를 직접 수정하고 싶어요
기술적으로는 가능합니다(~/.claude/commands/ 폴더의 .md 파일을 직접 편집). 다만 명령어 간 상호작용이 많아서 한 곳을 수정하면 다른 곳이 깨질 위험이 있어요. 수정 전 Claude에게 "이 명령어 이렇게 바꾸려는데 다른 명령어에 영향 있을까?" 라고 물어보시면 함께 안전한 방향을 잡을 수 있습니다. 단순 톤·문구 조정 정도는 직접 하셔도 됩니다.
Claude가 노션에 잘못된 걸 쓸까 걱정돼요
모든 명령어는 "미리보기 → 사용자가 '네'로 확인 → 실제 처리" 패턴입니다. 미리보기에서 한 번 더 확인하시고, 잘못됐으면 "아니오" 또는 "취소"로 안전하게 빠져나오실 수 있습니다. 일부 실패가 발생한 경우엔 자동으로 archive(노션 휴지통)로 롤백되므로 데이터가 완전히 사라지지는 않아요.
월 사용료가 얼마나 드나요?
Anthropic Claude(Claude Code) 구독료가 별도로 듭니다. 학원 운영 규모에 따라 Pro($20/월) 또는 Team 요금제 정도면 충분합니다. 자세한 가격은 anthropic.com에서 확인하세요. 노션·디스코드는 무료 플랜으로도 동작합니다.

7. 도움 요청

가이드대로 따라하시다 막히는 부분이 있거나, 명령어가 의도대로 동작하지 않더라도 걱정하지 마세요. 혼자 해결하실 필요는 없습니다. Claude Code 창에 자연어 그대로 말씀하시면, Claude가 함께 원인을 찾아 고쳐 나갑니다.

Claude는 이 가이드 내용과 22개 명령어 파일, 그리고 본인의 노션 DB 구조까지 모두 들여다볼 수 있어서, 사람한테 설명할 때보다 오히려 빠르게 진단할 수 있을 때가 많습니다.

💬 Claude Code에게 이렇게 말씀하시면 됩니다

완벽한 문장으로 정리하실 필요 없어요. 답답한 그대로, 평소 말투로 던지셔도 됩니다.

  • "방금 /수업결과 했는데 학생 목록이 안 떠. 노션에서는 잘 보이는데 왜 이러지?"
  • "/노션-템플릿연결 했는데 17개 중 2개 매칭이 안 됐어. 어떻게 해결해?"
  • "이런 에러가 떴어. 화면 그대로 붙여넣을게: (에러 메시지)"
  • "/일일피드백발송 메시지 톤을 좀 더 부드럽게 바꿀 수 있을까?"

💡 더 빠르게 도움받기 위한 팁

Claude에게 다음 정보를 함께 알려주시면 진단이 훨씬 정확해집니다. 모르겠는 항목은 비워두셔도 OK입니다.

  • 어떤 명령어를 실행했는지 (예: /일일피드백발송)
  • 에러 메시지가 떴다면 그대로 복사·붙여넣기 — 캡처 이미지보다 텍스트가 더 정확합니다
  • 본인 OS (Windows / Mac)
  • 의도한 결과 vs 실제 결과 — 예: "학생 5명 메시지가 가야 하는데 3명만 갔어"

🛡️ 안심하셔도 되는 부분

명령어들은 중요한 변경·발송 전에는 반드시 사람에게 확인을 받도록 설계되어 있습니다. 학부모 발송, 노션 데이터 변경, 일일피드백 일괄 발송 같은 작업은 Claude가 미리보기를 보여주고 "이대로 진행할까요? (네/아니오)"라고 묻습니다. 답답해서 이것저것 시도하셔도 큰 사고가 나기 어려운 구조예요.

🔄 그래도 안 풀리면

같은 문제로 Claude와 여러 번 시도해봤는데도 풀리지 않으면, 그 시도 과정 자체를 통째로 복사해서 Claude에게 다시 보여주세요. "이런 시도들을 해봤는데 다 안 됐어. 다른 방향으로 접근해볼 수 있을까?" 라고 물으시면 Claude가 다른 각도로 다시 접근합니다. 명령어 자체를 수정해야 하는 상황이면 Claude가 어떤 파일을 어떻게 고쳐야 할지 안내해드립니다.
