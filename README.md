# 노션 학원관리 슬래시 명령어 (Claude Code)

학원 운영을 Claude Code 슬래시 명령어로 자동화합니다.
옥토퍼스코딩 노션 학원관리 템플릿(17개 DB) 기반.

---

## 사용 방법

Claude Code 새 세션을 열고 아래를 그대로 붙여넣으세요:

```
이 GitHub repo의 SETUP_FLOW.md를 따라 내 컴퓨터에 노션 학원관리
명령어 시스템을 셋업해줘.

Repo: https://github.com/set-octopuslab/notion-academy-claude-commands
```

그 다음 Claude가 단계별로 묻는 것에 답하시면 끝입니다.
(OS·폴더 위치·노션 토큰·노션 페이지 URL·학원명 등을 차례대로 물어봅니다)

자세한 사용법은 `가이드/사용가이드.html` 참고.

---

## 사전 준비

1. Claude Code 설치 — https://claude.ai/code
2. 옥토퍼스코딩 학원관리 노션 템플릿을 본인 워크스페이스에 복제
3. 노션 Integration Secret 발급 — https://notion.so/profile/integrations

## 호환 가능 여부

같은 17개 DB 구조(학생·학부모·선생님·클래스관리·정규/보강 시간표·수강 등록·수업계획·일일피드백·주간 or 월간피드백·월간 수강료·월간 수강료 데이터·상담예약·상담결과·학원 캘린더·환불·운영 물품구매·게시판)를 갖춘 노션 템플릿이라면 동작합니다.

셋업 8단계에서 자동으로 DB 17개 매칭과 핵심 필드 점검을 수행합니다. 누락된 DB가 있으면 셋업이 중단되고 어떤 DB가 비었는지 알려줍니다.

## 막히는 부분이 있을 때

가이드대로 진행하시다 막히거나 명령어가 의도대로 동작하지 않으면, Claude Code 창에 자연어로 물어보세요. 이 가이드와 22개 명령어를 모두 알고 있어서 함께 진단·수정해드립니다.

자세한 문제 해결 방법은 `가이드/사용가이드.html` 의 **7. 도움 요청** 섹션 참고.
