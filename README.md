# 노션명령어 — 학원 운영 슬래시 커맨드 (배포용)

학원 운영을 자동화하는 Claude Code 슬래시 커맨드 모음입니다.
옥토퍼스코딩 노션 템플릿을 기반으로 설계되었으나, **동일 구조(16개 + 게시판 = 17개 DB)를 갖춘 노션 템플릿이라면 다른 학원에서도 동작**합니다.

> **⚠️ 이 `README.md`는 sync 대상에서 제외됩니다** (커맨드가 아니라 문서).
> 새 커맨드를 추가하면 **반드시 이 문서 표에도 한 줄 추가**하세요.

---

## 다른 학원 원장용 — 5단계 설치 시나리오

### 1) 노션 템플릿 복제

옥토퍼스코딩 학원관리 노션 템플릿을 자기 워크스페이스에 복제합니다. (배포된 공유 링크는 원장에게 문의)

복제 후 워크스페이스 내에 다음 17개 DB가 들어 있어야 합니다:
학생, 학부모, 선생님, 클래스관리, 정규수업 시간표, 보강수업 시간표, 수강 등록, 개인 수업결과(일일피드백), 수업계획·수업요약, 월간 수강료, 월간 수강료 데이터, 상담예약, 상담결과, 학원 캘린더, 환불, 운영 물품구매, 주간 or 월간피드백, 게시판.

### 2) 노션 통합(Integration) 권한 부여

- `notion.so/profile/integrations` 에서 Internal Integration 생성
- Integration Secret (ntn_ 으로 시작) 복사 — 4단계에서 사용
- 복제한 학원관리 부모 페이지 우측 상단 `…` → `연결` → 위에서 만든 Integration 선택

이렇게 하면 Claude의 노션 MCP 가 해당 페이지 + 하위 DB에 접근할 수 있습니다.

### 3) Git에서 명령어 폴더 clone

```powershell
git clone <repo-url> "G:/내 드라이브/ClaudeSetting/노션명령어"
```

또는 G드라이브 동기화 환경이 아니면 로컬 어디든 OK. 단, **sync 스크립트의 경로**(`G:/내 드라이브/ClaudeSetting/노션명령어`)와 맞춰주세요. 다르면 `hooks/sync-commands.sh`의 `REMOTES` 배열을 자기 경로로 수정.

### 4) Claude Code 새 세션에서 자동 연결

새 세션을 열고:

```
/노션-템플릿연결
```

Claude가:
1. 노션 MCP 연결 확인
2. 학원관리 부모 페이지 URL 받기 (사용자가 붙여넣기)
3. 워크스페이스 내 모든 데이터베이스 자동 검색
4. DB 제목 기준으로 17개 키에 자동 매칭 (애매하면 후보 보여주고 선택)
5. 학원명·디스코드 웹훅·노션 API token 등 수동 입력 항목만 물음
6. `notion-academy-config.json` 자동 작성
7. DB 필드 검증 (필수 필드 누락 시 경고)

수동으로 입력하고 싶다면 `/노션-초기설정` 사용 (결과 파일 동일).

### 5) 첫 명령어 실행

```
/결제선생 --dryrun
```

수강료 계산이 정상 동작하면 셋업 성공. 이후 `/학생-신규등록`, `/수강등록`, `/시간표등록`, `/출석`, `/수업결과` 등 22개 모두 사용 가능.

기존 `notion-academy-config.json` 가 이미 G드라이브에 있으므로 4단계 생략. clone 후 바로 사용.

## 등록된 커맨드 (22개)

### 학생 관리 (3)
| 커맨드 | 설명 |
|---|---|
| `/학생-신규등록` | 신규 학생을 학생 DB·학부모 DB에 한 번에 등록 (대화식, 미리보기 확인) |

| `/학생-퇴원처리` | 재원·휴원 → 퇴원 (선택적 미납·환불 검토 안내, 데이터 보존) |

|---|---|

| `/시간표변경` | 시간(요일·시각) 또는 횟수(주N회) 변경 + 디스코드 검수 |
| `/보강시간표등록` | 단발성 보강 수업 (결석 보강·자유 보강 통합) |
| `/휴강등록` | 캘린더 휴강 row + 영향 학생 일일피드백 자동 생성 + 디스코드 검수 |

## Config 파일 구조

학원 고유 값은 모두 `notion-academy-config.json` 한 파일에 모입니다.

- **저장 위치**: `G:/내 드라이브/ClaudeSetting/notion-academy-config.json` (G드라이브 공유) 또는 `~/.claude/notion-academy-config.json` (로컬 전용)
- **템플릿 파일**: `notion-academy-config.example.json` — 이 파일을 복사해서 사용하거나 `/노션-템플릿연결` 로 자동 생성

> **민감값** (웹훅 URL, 노션 API 토큰 등)은 `.gitignore` 에 의해 Git에 절대 올라가지 않습니다.

## 옥토퍼스코딩 노션 템플릿이 아닌 학원의 사용 가능 여부

같은 17개 DB 구조 (학생·학부모·선생님·클래스관리·정규/보강 시간표·수강 등록·수업계획/요약·개인 수업결과(일일피드백)·주간 or 월간피드백·월간 수강료·월간 수강료 데이터·상담예약·상담결과·학원 캘린더·환불·운영 물품구매·게시판)를 갖춘 노션 템플릿이라면 동작합니다. DB의 필드명·옵션값 일부가 달라도 `/노션-템플릿연결` 또는 `/노션-초기설정`이 매핑을 처리합니다.

핵심 필드(예: 학생 DB의 `학생이름`·`등록현황`·`초,중,고`, 수강 등록 DB의 `수강료 패턴 자동 판별용 필드` 등)가 빠져있으면 일부 명령어가 동작 안 합니다. `/노션-템플릿연결` 의 6단계 필드 검증에서 어떤 필드가 누락됐는지 확인할 수 있습니다.

템플릿 구조 자체가 크게 다르면 사용 불가. 그 경우 옥토퍼스코딩 노션 템플릿을 함께 도입해야 합니다.

## 동기화 원리 (요약)

- 원본 2폴더: `내명령어/` (개인용·sync) + `노션명령어/` (이 폴더·sync·Git 배포)
- sync 대상: `~/.claude/commands/<파일명>.md`
- 트리거: 세션 시작 시 `hooks/sync-commands.sh` 자동 실행
- 방향: G드라이브 → 로컬 단방향
- 충돌: 두 원본에 같은 파일명이 있으면 stderr 경고 (첫 원본만 복사)

상세는 `내명령어/README.md` 참고.
