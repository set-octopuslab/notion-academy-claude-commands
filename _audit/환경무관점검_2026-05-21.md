### 2-2. 🔴 월간피드백.md PowerShell 임시폴더 cross-platform 화

```diff
- $tempDir = "G:\내 드라이브\ClaudeSetting\temp\feedback-images"
+ $tempDir = Join-Path $HOME ".claude/cache/feedback-images"
```

## 4. 미해결 · 주의 사항

- **명령어 본문에서 사용자에게 `~/.claude/commands/` 로 .md 파일을 복사해야 슬래시 명령어가 인식된다**는 사실은 `README.md` 와 `setup/README.md` 에서 안내. `setup/sync-commands.{sh,ps1}` 가 그 작업을 자동화.
- **노션-게시판.md의 data_source_id 직접 박힘 (이전 audit 1번)** 은 이번 작업 범위 밖. 이전 PR에서 처리되었어야 함 — 메인 세션 확인 필요.
- **PowerShell `$HOME`** 은 Windows PowerShell 5.1, PowerShell 7, Bash 모두에서 사용자 홈으로 해석되지만, 일부 노출된 sandbox 환경에서는 다를 수 있음. 사용자별 1회 테스트 필요.
- **`이승환` 17건 유지 결정**은 작업 지시(이번 라운드)에 따른 것. 향후 완전 일반화 원하면 추가 라운드에서 처리.
- `노션-템플릿연결.md` 는 자신이 config 저장 위치를 결정하는 셋업 책임자이므로 "config 읽기" 라인 일괄 치환 대상에는 포함되지 않음 (다른 21개 명령어와 역할이 다름).
