## 항목별 상세

### 1. 노션-게시판.md (가장 큰 이슈)

`config.notion.data_sources` 키 목록에는 게시판(`boards`)이 없는데도, 이 명령어는 게시판 DB 3개의 id를 본문에 직접 박아 호출한다. 다른 학원에서는 동작 불가.

수정 방향:
- config에 `boards` 와 `boards_database` 키를 추가하도록 example/초기설정에 항목 추가
- 명령어 본문은 `config.notion.data_sources.boards` 와 `config.notion.boards_database_id` 참조로 교체
- 노션-초기설정 절차의 DB 매칭 후보에 `게시판` 포함되어 있음 (확인 완료)

### 2. 결제선생.md

- 254번 줄 `"매월 결제해야하는날짜": {"number": 25}` 의 `25` 는 옥토퍼스 결제일. config에 `tuition._매월_결제기준일` 이 있으므로 그것을 참조.
- 303번 줄 `User-Agent: Mozilla/5.0 (octopuscoding-webhook)` 는 디버깅 추적용 라벨. 학원 식별이 적힐 이유 없음 → 일반 라벨로 교체.

### 3. 수강등록.md / 학생-퇴원처리.md

본문 로직 내 안내 문구에 "옥토퍼스 패턴", "옥토퍼스 월간 청구" 표현. 다른 학원에서 그대로 출력되면 어색.

### 4. 노션-게시판.md / 노션-초기설정.md description

front-matter description은 슬래시 커맨드 메뉴에 노출되므로 학원명 박혀 있으면 어색. 일반화.

### 5. 예시 섹션의 학원명 (유지하는 것들)

다음은 **예시 섹션**이라 유지함 (사용자 지시에 따라 다른 학원도 예시로 이해 가능):
- 모든 명령어 본문 외 예시 흐름의 `이승환`(선생님), `파이썬`/`마인크래프트`(과목명)

이유: 예시는 사용 흐름을 보여주는 것일 뿐 실제 동작에 영향 없음. 다른 학원도 자신의 데이터로 치환해서 이해함.
